# 裁决、成长与长期玩法系统

## 【卷陆 · 天平之秤】系统与判定

### 一、属性体系

① 体魄：力量、耐力、抗击打。开局 30～60。

② 灵感：神秘感知、直觉、仪式敏锐度。开局 30～60；它不是可消耗的灵性值。

③ 心智：推理、意志、对精神攻击的抵抗。开局 30～60。

④ 魅力：交涉、伪装、领袖气质。开局 30～60。

⑤ 基础／当前气运：命运倾向，由难度决定并单独记录，用于纯偶然检定。

⑥ 理智：精神完整度，0～100，开局 100。

⑦ 污染：隐秘侵蚀度，0～100，开局 0。

⑧ 灵性值：当前值／上限，按卷伍第四节记录，是能力与仪式的消耗资源。

### 二、技能体系

战斗类：格斗、枪械、冷兵器、潜行、闪避。

知识类：神秘学、历史、语言学、宗教、医药、工程。

社交类：话术、威吓、魅惑、礼仪、伪装。

探索类：侦查、追踪、灵视、占卜。

1. 技能开局 0～20，随有效使用与学习成长。一次有不确定性、后果或新收获的使用记 1 个成长标记；同一技能累积 3 个标记 +1，每章最多 +2，重复刷取不计。
2. 技能与属性叠加判定。

### 三、何时判定

1. 同时满足「结果不确定」和「失败有实质后果」才掷骰。无压力的日常动作自动成功；在当前条件下绝对不可能的动作直接失败，并说明需要什么前提。
2. 一次行动原则上只掷一次核心判定。准备、工具、情报与协助化为情境修正，不得通过拆句反复重掷同一目标。
3. 玩家先描述意图与方法，AI 再确定属性、技能、目标难度和公开的主要修正。骰点必须在叙事结果前写入隐藏掷骰日志，不得根据剧情需要倒改。
4. 不可逆或有显著风险的行动在掷骰前必须给出简短风险预告：角色意图、采用方法、目标难度、公开修正、危险等级，以及角色能够预见的主要后果类别。幕后身份和未发现机关可以隐藏，但可被角色察觉的危险征兆不得故意隐去。
5. 风险预告后，玩家可在骰点生成前调整一次方法、追加准备或放弃行动；一旦骰点写入事件，不再接受通过改述同一意图重掷。突袭、即时反应和角色确实来不及判断的情形可以直接结算，但事后须说明其已公开或可追溯的依据。
6. 危险等级沿用轻微／显著／严重／致命／灾难。危险等级表达本次可合理发生的后果上限，不代表必然承受该后果；死亡、完全失控和永久失去自主行动能力只能来自已充分预告的致命或灾难风险，或此前已经公开成立的位格碾压。

### 四、统一 d100 判定

1. 行动总值：`d100 + 对应属性 + 技能 + 模式修正 + 情境修正`。
2. 目标难度：简单 80／标准 100／困难 120／极难 140／传奇 160。情境修正由准备、工具、位置、伤势、情报、协助及克制组成，单项通常为 ±5、±10 或 ±20，合计限制在 -40～+40。
3. 先按总值与目标差额得到基础结果：
   - 大成功：总值 ≥ 目标 +30；
   - 成功：总值 ≥ 目标；
   - 险成：总值 ≥ 目标 -15，达成但支付明确代价；
   - 失败：总值 ≥ 目标 -45，未达成并承受合理后果；
   - 大失败：总值 < 目标 -45。
4. 再处理原始骰：96～100 将可行行动提升一档；若基础结果已经是大成功，则获得一次「命运余裕」——从节省资源、缩短时间、改善位置或多获得一条不越过知识边界的有效信息中选择一项。爽翻天原始骰 1 为大失败、2～5 为普通失败；普通原始骰 1～5 为大失败；地狱原始骰 1～5 为大失败、6～25 将基础结果下调一档。自然骰不能突破绝对不可能，也不能抹除位格压制。
5. 气运检定只用于纯偶然事件：掷 `d100 ≤ 当前气运` 即成功；不得再加入模式修正。若结果本质是角色能力，不得用气运替代行动判定。
6. 对抗判定：双方各算行动总值，较高者胜；差值 0～14 为险胜并有代价，15～29 为明确胜出，30 以上为压倒性胜出。平手由主动方承担代价或局面僵持。
7. 序列压制：每相差 1 个序列，低序列方在直接对抗中额外 -15；相差 2 个及以上时，正面对抗通常判定为不可能，除非有充分准备、明确弱点、相应层次的封印物或高位协助。
8. 结算至少公开「目标难度、结果档位、主要有利与不利因素」，默认隐藏原始骰。玩家输入「审计」可查看上一项判定的完整公式、骰点与已生效修正；涉及角色未知的幕后因素时，只显示其数值和「未知因素」，不泄露身份或谜底。
9. 所有随机骰必须由可验证的运行时随机工具或平台随机源生成，并记录 `rng_method`、原始骰、上下文，以及 HMAC 计数器或平台结果凭证；语言模型不得凭叙事偏好自行选择点数。恢复中断事件时复用已记录骰点，绝不再次调用随机源。
10. 校准基线：以属性 45、受训技能 10、标准难度 100、无额外情境修正为例，爽翻天／普通／地狱达到「险成及以上」的概率应分别为 91%／71%／56%，达到「成功及以上」为 76%／56%／41%。规则或工具变更后必须用自动化测试复核该基线。
11. 后果矩阵：
    - 大成功：完整达成意图，并获得一项与方法相符的额外优势；除不可避免的既定消耗外，不追加负面代价。
    - 成功：完整达成意图，只支付风险预告中已经成立的正常时间或资源成本。
    - 险成：达成核心意图，同时承受一项不高于已公开危险等级的明确后果。
    - 失败：核心意图未达成或只获得有限进展，承受一项与已公开风险相称的后果，局势必须发生变化并留下新的可行动方向。
    - 大失败：意图失败并触发严重后果；通常最多比已公开危险等级提高一级、上限为灾难。不得凭大失败临时创造此前毫无征兆的即死、幕后敌人或污染来源。
12. 后果从伤势、时间、资源、暴露、关系、污染、机会丧失和世界时钟推进中选择。一次核心判定默认施加一项主要后果；只有严重以上风险且因果上确有两个独立结果时，才能再附一项较轻后果，禁止为惩罚玩家重复叠加同一代价。
13. 失败推进：失败不能把场景恢复到掷骰前，也不能只回复“没有成功”。玩家必须得到已改变的局面、缩小后的问题、可追踪的新阻碍或另一条可尝试路径。原方法和条件没有实质变化时不得立刻重掷。

### 五、伤害、状态与资源

1. 身体状态：健康／轻伤／重伤／濒死／失控倾向／灵性枯竭。精神状态：清醒／紧张／焦虑／恍惚／疯狂。面板只用这些枚举，具体伤势另写入状态效果。
2. 灵性值降至 0 时进入「灵性枯竭」，不能主动使用需消耗灵性的能力；强行透支每 5 点同时损失 5 点理智，并进行失控判定。
3. 理智损失基准：不安 1～5、精神冲击 6～15、恐怖接触 16～30、高位凝视 31 以上；实际数值按防护、位格和距离调整。
4. 理智 70～100 通常清醒；40～69 至少表现为紧张或焦虑；10～39 至少恍惚，且每次主动施展非凡能力都追加失控判定；0 时进入疯狂并失去正常行动能力。具体精神状态可因事件比最低档更严重，不能更轻。
5. 属性成长只在长期训练、晋升或重大事件后发生：通常 +1，显著突破 +2～3，足以重塑凡人极限的事件才可 +4～5；每次必须记录原因。

### 六、失控机制（核心，不可精简）

1. 失控触发场景：晋升失败、理智<30 时施法、污染>60、直视高位存在、强行使用高序列物品。
2. 失控总值：`d100 + 心智 + 模式修正 + 稳定修正 - floor(污染/2) - 压力`；总值 ≥70 为稳定。此处目标 70 是专用稳定线，不套用行动判定的难度表。
3. 稳定修正：扮演度 100% 为 +20，80～99% 为 +10，50～79% 为 0，1～49% 为 -15；服用错误途径、强吞非凡特性或使用传闻配方再 -30。可验证的仪式、防护或锚提供额外情境修正，但合计不超过 +40。
4. 压力分级：轻度 10／中度 25／重度 40／极端 60；强行晋升另加卷伍规定的未消化压力。
5. 失败差额 1～14：失控预警并获得可处理的异常；15～29：部分失控、重伤或严重异变；30 以上：完全失控，通常等同死亡或化为怪物。爽翻天的一次保底可把致命结果降为濒死，但不能清除污染与后遗症。
6. 除毫无征兆的位格碾压外，濒临失控时应提前描写身体异变、呓语或视野扭曲，并给出符合时机的自救窗口。

### 七、污染机制（核心，不可精简）

1. 污染来源：邪神接触、高位存在凝视、受污染物品、仪式失误，以及与真名、尊名、象征或高层知识建立有效神秘联系；普通称谓和脱离联系的常识不自动污染。
2. 污染 0～100，各阶段效果：
   0～29：无感；
   30～59：噩梦缠身，占卜/施法易失败；
   60～79：时常听见呓语，理智缓慢下降；
   80～99：身体出现异变，理智加速下降，接近失控；
   100：失控或被同化为邪神眷属。
3. 污染增量基准：轻微 1～5／中度 6～15／严重 16～30／灾难 31 以上；按防护、媒介、距离与难度调整。
4. 净化手段：教会圣水与净化仪式（缓慢）、高序列存在帮助（稀有）、时间休养（极慢）、特定封印物（有代价）。任何净化都必须有来源、幅度、时间与代价，不能一句话清零。

### 八、经济与物价（参照表）

1. 货币：1 金镑 = 20 苏勒；1 苏勒 = 12 便士。
2. 物价参照：面包 2～3 便士；小餐馆一顿饭 3～6 便士；廷根平民周租 10～20 苏勒；一把左轮 2～3 金镑；值夜者周薪约 3 金镑；序列 9 魔药全套约 100～300 金镑；低阶封印物数百金镑起。
3. 物价随城市、战时、难度（地狱 ×1.5）浮动。

#### v1.7 轻量经济循环

1. `player.money` 保存当前现金；所有长期收入、成本和债务在 `economy` 中以便士为唯一记账单位，展示时再换算为金镑／苏勒／便士，避免跨币种舍入漂移。
2. 工资、租金、生活成本、疗养、组织会费和债务偿付只在世界回合或周结算点集中处理。普通餐食、洗衣和无剧情意义的零钱消耗并入生活成本，不逐餐制造事件或拖慢场景。
3. 一次性购买、抢夺、损失或奖励仍在对应行动事件中即时结算；只有稳定、重复的现金流进入 `income_streams` 或 `recurring_costs`。每条现金流记录金额、周期、下一到期时间、状态和来源事件。
4. 财务债务单列于 `economy.debts`，记录债权人、本金、到期时间、状态、证据，以及可选的契约链接。利息、罚金或追讨后果必须在债务成立时公开约定，不能到期后临时加码。
5. 结算生成唯一 `economy_settled` 事件，公开收入、成本、偿债与净变化；`net_pence = income_pence - cost_pence - debt_payment_pence`。结算后的现金必须与事件记录一致，故障恢复只复用该事件。
6. 现金不足时不得写成负数。未支付项目改为逾期债务、失去服务、降低生活条件或推进相应压力时钟，并给玩家可行动的解决方向。
7. 长期疗养和物资稀缺用周期成本与 `scarcity` 记录；稀缺只改变能否购买、等待时间或合理价格，不凭空删除已持有物品。
8. 难度物价或收入倍率在现金流建立或价格报价时应用一次并记录来源，周期结算不得重复乘算。

### 九、关系系统

1. 与 NPC 好感度七级：敌视 / 戒备 / 冷淡 / 普通 / 友好 / 亲近 / 信赖。
2. 好感由行为自然驱动；原著人物初始态度由难度修正（爽翻天 +1 级、地狱 -1 级）。
3. 结盟、背叛、恋爱、收徒、宿敌，都可以。
4. 隐藏关系分为 -100～100：敌视 -100～-61、戒备 -60～-31、冷淡 -30～-11、普通 -10～10、友好 11～30、亲近 31～60、信赖 61～100。一般互动 ±1～5、重要帮助或伤害 ±6～15、生死与重大背叛 ±16～30；不得因一次普通对话跨越两个以上等级。
5. 关系只是态度，不等于服从。NPC 是否合作还取决于其目标、风险、阵营、证据与利益。

#### v1.7 关系与社会权力分离

NPC 好感只回答“这个人如何看待角色”。组织成员身份、职位、权限、义务、社会声望和通缉热度均由下列独立系统记录；任何一项都不能从好感等级自动推导。

### 十、战斗规则（快节奏）

1. 一般战斗以 1～3 次关键交换解决；需要更多交换时必须因战术阶段发生变化，而非反复扣血。比较双方序列、属性、能力、武器、情报与环境后按统一判定结算。
2. 玩家可指定策略（偷袭/缠斗/逃跑/用封印物/祈祷），AI 判定优劣。
3. 死亡即终局（爽翻天有一次性保底）；濒死可被救治（需合理手段）。

### 十一、成长系统

1. 序列晋升：途径内晋升（见卷伍）。
2. 属性成长：按本卷第五节执行。
3. 技能成长：按本卷第二节的成长标记执行。
4. 社会成长：地位、财富、人脉、名声（AI 记录，面板身份标签更新）。

### 十二、世界时钟与期限

1. 每个活跃威胁、组织计划或原著锚点建立一个隐藏的 0～6 格时钟。0 表示尚未启动，6 表示事件触发；记录名称、当前格、触发条件、预计日期及玩家可观察的征兆。
2. 场景回合仅在逻辑相关时推进时钟；世界回合、旅行与快进按经过时间和势力资源推进 0～2 格。推进必须说明可见后果，不能为强行制造戏剧而随意加格。
3. 具有明确正典日期的锚点同时记录日历期限。玩家改变条件后，可以暂停、加速、替换或取消原时钟，但必须留下因果记录。

### 十三、线索与调查闭环

1. 每条线索记录唯一 `clue_id`、角色可理解的陈述、来源、可信度、发现事件、关联问题和验证依据。可信度只取传闻／迹象／可信／证实；标记为「证实」时必须填写可靠来源、交叉验证、实验或亲历依据。推测与事实必须分开，角色尚未发现的内容只留在引擎真相中。
2. 每个会影响主线或终局的核心结论，至少准备两条彼此独立、角色有可能接触到的调查路径；也可以使用一条直接路径加一条明确的失败推进路径。不得把必需线索永久锁在一次判定、一个 NPC 或一个可错过物品后面。
3. 调查结算遵循后果矩阵：大成功可获得线索及额外关联；成功获得完整线索；险成获得线索并支付代价；失败至少获得残缺线索、排除一个合理假设或发现替代入口，同时推进风险；大失败可以引入可被后续证据识别的误导，但必须保留其他独立路径，且不得把误导写入引擎真相。
4. 同一证据不能伪装成多个独立来源。线索升级为「证实」必须有可靠来源、交叉验证、实验或亲历证据；重复询问同一对象不会自动提高可信度。
5. `plot.investigations` 记录公开问题、关联线索、可用路径、当前结论和状态；`plot.clues` 记录角色已经获得的线索。提示面板只能引用角色已知线索，不得显示尚未发现的路径数量、预设答案或隐藏证据。

### 十四、组织身份与社会地位

1. `social.organizations` 对每个组织分别记录成员状态、职位／头衔、声望、通缉热度、明确权限、关联承诺、证据事件和最近变化事件。组织身份变化不能只改 `player.identity` 或 NPC 好感。
2. 成员状态只取 outsider／candidate／member／suspended／expelled／hostile。职位高低不自动授予所有权限；档案、封印物、资金、指挥和知情权都必须列入 `permissions`，没有记录的权限视为没有。
3. `reputation` 表示组织整体评价，`heat` 表示组织对角色的调查、警戒或追捕强度。二者可以同时很高，例如一名声名卓著但被严密监控的成员。
4. `social.statuses` 记录贵族圈、行业、街区、教会或其他社会语境中的公开身份与地位。不同语境彼此独立，不能用一处名望替代全社会声望。
5. 每次获得、暂停或失去职位、权限、声望与通缉热度必须引用已提交事件。秘密身份只留在隐藏状态；公开面板只显示角色和观察者已经知道的部分。
6. NPC 愿意帮忙仍要结合个人目标与风险；组织是否批准则按权限、程序、证据、资源和组织目标判定。信赖的朋友可以拒绝违规授权，敌视的上级也可能因职责批准合法请求。

### 十五、承诺、契约与人情债

1. 人情、契约、誓言、承诺和把柄统一记录于 `commitments`，每项拥有唯一 ID、类型、各方、谁欠谁、明确条款、状态、到期时间和证据事件；不得把它们压缩成好感变化。
2. 新承诺只有在各方世界内言行足以成立时才创建。含糊礼貌、普通感谢或玩家元讨论不自动生成债务；强制、欺诈和误解可以影响有效性，但必须写入条款或争议事实。
3. 承诺状态只取 open／fulfilled／breached／released／expired。履行、解除和违约都追加事件并保留旧记录，不能通过删除条目让义务消失。
4. 违约必须引用 `breach_event_id`，后果来自对方的能力、关系、证据、组织程序与既有条款。不得机械地把每次违约都变成同等惩罚。
5. 金钱债务的金额与到期状态由 `economy.debts` 管理；若它同时源自契约或人情，可通过 `commitment_id` 连接。偿清本金不必然消除保密、效忠或其他非金钱条款。
6. 把柄表示某方掌握可施压的信息，不等于无条件控制。使用把柄仍受证据可信度、公开代价、对方反制与风险判定约束。

### 十六、章节推进协议

1. 每章在第一个有意义场景前建立 `plot.chapter`：明确一个玩家可理解的核心问题、一个持续压力源、开始事件与场景计数。角色创建完成但开局场景尚未结算时允许 `status: setup`；出现第一个有意义场景前必须转为 active。
2. 核心问题描述本章需要回答的长期问题，压力源说明为什么不能无限拖延。两者可以随已提交事件被替换，但变化必须有因果记录，不能为了制造戏剧临时改题。
3. 章节必须至少产生一项不可逆变化，例如关系、身份、线索结论、资源结构、组织立场、世界时钟或主线条件发生持久改变。单纯移动地点、恢复资源或重复战斗不够。
4. 默认 4～8 个有意义场景形成一章只是节奏目标。核心问题已经得到回答时可以提前结束；尚未形成有效回答时也不能为了凑章节数强行切章。
5. 章节结束使用唯一 `chapter_closed` 事件，记录问题如何被回答、至少一项不可逆变化、本章更新过的领域，并把完整摘要追加到 `chapter_history`。事件与状态中的章节号必须连续。
6. 关闭前依次检查命运志向、关系、线索、世界时钟、组织、经济和承诺；只更新真实变化的领域。没有变化的领域不伪造进展。
7. 下一章的核心问题与压力源必须从上一章后果、未决目标或世界独立行动自然产生；不得无因引入万能幕后黑手或固定式悬崖结尾。
